Core capabilities

Everything a real IDS needs

Built from scratch over 8 days using Python, PHP, MySQL, and JavaScript. No third-party IDS engine — every component is custom.

⚡
Real-time packet capture
Scapy-based packet sniffer captures live network traffic from any interface. Processes packets at up to 500/sec with per-IP rate tracking.
capture.py · Scapy
🧠
ML anomaly detection
Isolation Forest model trained on normal traffic profiles. Detects statistical anomalies alongside rule-based classification for 8 threat types.
scikit-learn · Isolation Forest

AI threat explanation
Every alert can be explained in plain English by GPT-4o-mini. Tells analysts what the threat means, why it's dangerous, and what to do.

Detection engine

8 threat types classified

Rule-based and ML-based detection running in parallel. Rule engine handles known patterns; Isolation Forest catches unknown anomalies.

Critical
C2 Communication
Traffic to known command-and-control ports. Immediate block.
Critical
SYN Flood
TCP SYN packets at 100+ per second from same source IP.
Critical
DoS / UDP Flood
High-volume traffic designed to exhaust server resources.
High
Port Scan
15+ unique destination ports from one IP within 10 seconds.
High
Brute Force
Repeated authentication attempts on SSH, RDP, FTP, Telnet.
High
DNS Amplification
Oversized UDP packets on port 53 used for reflection attacks.
Medium
XMAS / Null Scan
TCP packets with abnormal flag combinations for stealth recon.
Low
ML Anomaly
Statistical outlier detected by Isolation Forest — unknown threat.
Quick start

Up and running in 4 steps

Requires WAMP Server, Python 3.11, and VS Code. Full 8-day build guide available in the project docs.

Step 01
Install dependencies
# Install Python packages
pip install flask flask-socketio scapy
        scikit-learn pandas requests
        python-dotenv mysql-connector

# Start WAMP (tray icon = green)
Step 02
Create the database
-- phpMyAdmin → SQL tab
CREATE DATABASE ids_db;
-- Run schema.sql (6 tables)
-- alerts, rules, blacklist,
-- users, settings, logs
Step 03
Configure .env
API_KEY=ids-api-key-change-me
DB_HOST=localhost
DB_USER=root
ABUSEIPDB_KEY=your_key
OPENAI_KEY=sk-...
TWILIO_SID=AC...
Step 04
Launch everything
# Start the full system
python main.py

# Open in browser
http://localhost/ids/

# Real capture (run as Admin)
python capture.py --iface "Wi-Fi"
